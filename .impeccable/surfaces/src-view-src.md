## Direction contract

THESIS: This is a working instrument for two people doing dense thesis-grade reading, not a consumer chat product — it reads as a precise terminal-grade research tool. Refuses the generic card-and-chat-bubble SaaS look this category defaults to.

OWN-WORLD: Bright paper-white ground, near-black ink, warm amber-orange accent used sparingly (active state, primary action, citation chips) — never as a background wash. Flat panels, 1px hairline borders, no drop shadows as decoration. Micro-labels (uppercase, tracked) restrained to functional status/section labels, never decorative kickers. Monospace reserved strictly for literal code blocks and `[n]` citation markers; a clean sans (Claude-Code-adjacent, system-leaning) carries everything else, including equations' surrounding prose.

STORY: Upload a paper → it lands in a slim collapsible rail with a status chip. Ask a question → bullet answer streams in, each claim ending in an `[n]` chip. Click the chip → a small card anchored right at that chip shows the quoted excerpt or figure, no page jump, no scroll to a list below.

FIRST VIEWPORT: Slim top bar (app mark, sidebar toggle). Collapsible left rail: dropzone, paper list with status chips. Chat column fills remaining width: message stream, composer pinned to the bottom, citation popovers anchored inline to their chip.

FORM: Redesign (new-work.md §1) — replaces the existing blue-accent card-chat look, pinned brief (bright + orange + Claude-Code-adjacent + anti-slop), code-led build, Operate mode depth rules apply throughout.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
